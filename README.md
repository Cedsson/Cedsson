### What I build

* **[Krut Engine](https://cedsson.github.io/#engine)** — A solo-developed 3D game engine (~58k LOC in C#/.NET 10). Features a custom Forward+ renderer (Direct3D 12 & Vulkan), Native AOT builds, and a Quake/Source-style BSP level workflow.
* **[Krut.Netcode](https://github.com/Cedsson/Krut.Netcode)** — Open-source, zero-allocation authoritative netcode library in .NET with client prediction, snapshot interpolation, and link degradation simulation.
* **[Krut.Racing](https://cedsson.github.io/#racing)** & **[Commute](https://cedsson.itch.io/commute)** — Games built on top of the engine, including an authoritative multiplayer racer with an ASP.NET Core & PostgreSQL backend.
