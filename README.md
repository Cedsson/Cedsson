### 📦 Featured Open Source

#### ⚡ [Krut.Netcode](https://github.com/Cedsson/Krut.Netcode) `MIT License`
> *Authoritative-server netcode library in modern .NET designed for low-latency, real-time multiplayer.*

- **Zero Allocations:** Custom serialization generating 0 B of steady-state GC allocations.
- **Client Prediction & Reconciliation:** Instant local inputs with tick rewinds & smooth correction blending.
- **Network Link Simulator:** Test resilience under artificial packet loss, jitter, and latency spikes.
